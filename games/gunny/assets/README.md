# Planet imagery

Earth and Moon maps by [Solar System Scope](https://www.solarsystemscope.com/textures/), based on NASA elevation and imagery data. Licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

Downloaded September 21, 2026. Bundled locally; no runtime third-party image requests.

| Local file | Original |
| --- | --- |

| `earth-night.jpg` | [2k_earth_nightmap.jpg](https://www.solarsystemscope.com/textures/download/2k_earth_nightmap.jpg) |
| `earth-clouds.jpg` | [2k_earth_clouds.jpg](https://www.solarsystemscope.com/textures/download/2k_earth_clouds.jpg) |
| `earth-ocean.jpg` | [2k_earth_specular_map.tif](https://www.solarsystemscope.com/textures/download/2k_earth_specular_map.tif), converted to JPEG |
| `moon.jpg` | [2k_moon.jpg](https://www.solarsystemscope.com/textures/download/2k_moon.jpg) |

All maps are 2048 × 1024. Other than the specular-map format conversion, source pixels are unchanged. In-game shaders add lighting, cloud transparency, and atmosphere. Attribution also appears in the launch panel.
